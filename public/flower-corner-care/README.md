# Watercolor care examples

Eleven AI-generated botanical watercolor vignettes, created 2026-11-03. Each original is a 1254 × 1254 RGBA PNG with genuine transparency, preserved unchanged. No cropping, resizing, paint-over, alpha modification or recompression was applied.

These are illustrative examples, not exact pictures of every plant that uses a shared technique mode. The plant-specific text determines whether, when and where to cut. The example plant is disclosed in `lib/flower-care-art.ts`; generation prompts, descriptions and source examples are in `provenance.json`.

Visual checks cover the pictured action and living tissue retained: pinching above a leaf pair, deadheading above healthy growth, a light trim above leafy growth, dead-stem cleanup above the crown, natural bulb-leaf dieback, intact woody buds, a spent bulb flower removed above leaves, an independent flower stalk removed near its base, a flower spike removed above foliage, one dead leaf selected outside healthy new growth, and an untouched living crown.

The woody, bulb and leave-intact examples deliberately contain no cutting tools or cut marks. Transparent edges should be reviewed on the intended light page background. The full square should remain visible; do not use sprite offsets or legacy clipping.
