# Flower Garden botanical portraits

My flowers reuses the Plant Vault botanical portrait renderer, preserving saved image URL precedence and exact cultivar matching. The Cut Flower Encyclopedia uses two original raster atlases, covering all thirty entries in `lib/flower-garden-art.ts`. Existing seasonal banners and bouquet arrangements remain available.

Artwork created with the built-in image-generation tool, using the owner's approved seed illustrations as a style reference. Prompt set: sophisticated seed-catalog botanical watercolor with colored-pencil detail; realistic petals, foliage and growth forms; pure white background; separate centered specimens in four-by-four invisible square cells with generous margins; no photographs, cartoons, text, prices, quantities, labels, packets or grid lines. Subjects follow the row-major order in the manifest.

Specific directions distinguish traditional closed snapdragon flowers from open-faced Chantilly snapdragons, golden Rudbeckia from muted copper/terracotta/rose Sahara blooms, white lace Orlaya from Ammi majus umbels, and white/pink panicle hydrangeas from the user's pink mophead cultivar portrait. Zinnias have pink/orange/yellow flowers rather than Queen Lime flowers. Unspecified encyclopedia colors are representative, as described on the existing page.

Project assets: `public/flower-portraits/botanical-cut-flowers-1.webp` and `public/flower-portraits/botanical-cut-flowers-2.webp`. WebP exports retain the complete generated atlas composition. CSS viewports select individual specimens without altering the original artwork. Original generated PNGs remain in the creation workspace.

Verification covers all thirty distinct entries and loaded assets, saved image precedence, My flowers and encyclopedia navigation, and desktop/tablet/mobile layouts. No account data, plant categories, wishlist selections or synchronization code is changed.
