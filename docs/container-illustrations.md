# Illustrated pots and planters

Eleven selectable original watercolor/gouache raster assets replace the generic circle in Garden View: classic terracotta, ivory porch planter, glazed blue pot, stone urn, cedar box, galvanized trough, fabric grow bag, sage window box, hanging basket, oak half-barrel and tall square planter. Plan View keeps schematic geometry for editing. Existing container records without a style use the terracotta illustration without rewriting stored data. Styles can be changed independently of names, dimensions, plants and growing-space links.

Plan & Design offers a collapsible inspiration gallery. Add container opens an illustrated chooser; the selected vessel supplies a starting shape. Photo review can select a vessel style before saving, and the detection schema accepts only approved style IDs. Unknown saved styles cannot load arbitrary image URLs. Existing courtyard template copies use varied vessels; existing saved layouts keep their objects and plant records. Decorative plants remain independently editable, visually raised toward the vessel rim.

## Artwork provenance and prompts

Created with the built-in image generation tool, transparent backgrounds. User-provided planter references informed the requested material variety and realistic, non-cartoon direction; no ads, text or brands were copied. Original generated PNGs were retained; project assets are alpha-preserving trimmed/downscaled WebP images in public/container-art. No programmatic drawing substitutes were used.

Common prompt for the first eight assets: "Use case: stylized-concept. Production botanical illustration asset for Garden Atelier's editable garden designer. Create ONE isolated [subject]. Sophisticated hand-painted watercolor and fine gouache, realistic dimensional form, meticulous natural material textures, gentle warm daylight, premium botanical journal aesthetic. Three-quarter slightly elevated front view showing a shallow ellipse/rectangle of rich dark garden soil near the rim. No plants: the application adds its own botanical plant illustrations separately. Center whole object in a square image, occupy about 85% width and 80% height, all edges visible, no clipped handles or feet. Truly transparent background with clean alpha, no white halo, no backdrop, no floor, no text, no labels, no brands, no frame. Not a photograph, not cartoon, not flat geometry. This is a recognizable three dimensional illustrated planter, not a circle diagram."
